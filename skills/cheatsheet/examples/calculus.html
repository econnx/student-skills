Calculus 1 — Test 2 (derivatives, Taylor, curve sketching)

1. Derivative rules

(u ± v)′ = u′ ± v′ · (uv)′ = u′v + uv′ · (u/v)′ = (u′v − uv′)/v², v ≠ 0

(f(g(x)))′ = f′(g(x))·g′(x)

(xⁿ)′ = nxⁿ⁻¹ · (eˣ)′ = eˣ · (aˣ)′ = aˣ ln a · (ln x)′ = 1/x, x > 0

(sin x)′ = cos x · (cos x)′ = −sin x · (tg x)′ = 1/cos²x

(arcsin x)′ = 1/√(1−x²) · (arctg x)′ = 1/(1+x²)

chain rule: never forget g′(x)

2. Tangent and differential

tangent at x₀: y = f(x₀) + f′(x₀)(x − x₀)

f(x₀ + Δx) ≈ f(x₀) + f′(x₀)Δx — for small Δx

3. L'Hôpital's rule

lim f/g = lim f′/g′ — only for 0/0 or ∞/∞, and if the right limit exists

0·∞ → rewrite as 0/0 · 1^∞, 0⁰, ∞⁰ → e^(lim g·ln f)

check the form before every application

4. Taylor / Maclaurin

f(x) = Σ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ + Rₙ(x), k = 0…n

Lagrange remainder: Rₙ(x) = f⁽ⁿ⁺¹⁾(c)/(n+1)! · (x−a)ⁿ⁺¹, c between a and x

error ≤ M·|x−a|ⁿ⁺¹/(n+1)!, M = max |f⁽ⁿ⁺¹⁾| on [a, x]

eˣ = 1 + x + x²/2! + x³/3! + … · sin x = x − x³/3! + x⁵/5! − …

cos x = 1 − x²/2! + x⁴/4! − … · ln(1+x) = x − x²/2 + x³/3 − …, −1 < x ≤ 1

(1+x)ᵅ = 1 + αx + α(α−1)/2! · x² + …

alternating series: error ≤ first dropped term

5. Monotonicity and extrema

  1. domain
  2. f′(x), solve f′ = 0 and find where f′ does not exist
  3. sign table of f′: + rising, − falling
  4. + → − max, − → + min

on [a, b]: compare f at critical points and at a, b

6. Convexity and inflection

f″ > 0 convex ∪ · f″ < 0 concave ∩

inflection: f″ changes sign (f″ = 0 alone is not enough)

7. Asymptotes

vertical x = a: lim f(x) = ±∞ as x → a (check gaps of the domain)

horizontal y = b: b = lim f(x), x → ±∞

oblique y = kx + b: k = lim f(x)/x, b = lim (f(x) − kx)

x → +∞ and x → −∞ separately: k and b may differ

8. Curve sketching plan

domain → parity → zeros → asymptotes → f′ (extrema) → f″ (inflection) → table → graph

9. Optimization

variable → function of one variable → domain → f′ = 0 → check it is a max/min → answer with units
