# Exam prep

Build a practice exam only from the student's own materials, so it matches what the course actually covers.

## Steps

1. **Collect the materials.** Files, folders, pasted notes or slides. Ask what the exam format is (multiple choice, short answer, problems, essay) and how much time they have. If they don't know, use a mix.
2. **Map the topics.** List the main topics with one line each and how much space each takes in the materials. Show this list first, so the student can say what to skip.
3. **Write the exam.** About 60% core definitions and concepts, 30% applying them (a small case, a calculation, "what happens if"), 10% harder questions that connect two topics. Put the page or slide each question comes from in the answer key.
4. **Quiz mode.** If the student wants, ask the questions one by one, wait for each answer, then say right or wrong, give the correct answer in one or two sentences and where to reread it.
5. **Finish with the weak spots:** the topics they got wrong and what to reread, in order.

## Rules

- Never invent facts that are not in the materials. If something important seems missing, say so instead of filling the gap.
- For calculations, show every step in the answer key.
- Use the language of the materials unless the student asks for another one.
